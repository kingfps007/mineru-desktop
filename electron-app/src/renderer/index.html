ℹ 关于 MinerU Desktop v3.1.4
程序功能实现流程:

1. 环境检测 (启动时)
· find_conda() 扫描 C:/ProgramData、~/.conda → 不到1ms
· detect_mineru_env() 检查 envs/MinerU/python.exe 文件存在性 → ms级
· detect_gpu_fast() 调用 nvidia-smi --query-gpu → <50ms
· detect_models_fast() 读取 mineru.json 配置 + 检查模型关键文件存在 → ms级
· capability_assessment() 综合以上信息输出四级能力评估 (full/capable/limited/basic)
· detect_gpu_deep() 调用 conda run -n MinerU python -c "import torch" → 5-15s (后台异步)

2. 批量解析 (方式一: Zotero)
· parse_zotero_json() 读取 BetterBibTeX JSON → 提取 citationKey/title/PDF路径/Debd
· 前端 renderRefTable() 渲染文献表格 (citekey/标题/PDF大小/已完成/待解析/无PDF)
· 勾选文献 → POST /api/parse/start → run_parse() 逐篇调用 mineru CLI
· mineru -p -b -l -o /
· output = .md + images/ 子目录
· GPU 温度 >70°C 自动暂停30秒散热 → 继续
· 每篇失败自动重试最多3次 · 中断后已完成的跳过不重复解析

3. 批量解析 (方式二: 直接选文件)
· Electron dialog.showOpenDialog 多选 PDF/DOCX/PPTX/XLSX/图片
· POST /api/files/import → 文件列表 (name/path/size/type/valid)
· POST /api/files/parse → 同 run_parse 流程

4. Markdown → Zotero Word
· load_bbt() 从 JSON 建立 citationKey → Zotero URI 映射
· process_inline_text() 正则匹配 [@citekey] → make_citation_json() → ADDIN ZOTERO_ITEM 域代码
· 图片 ![]() → add_picture() · 表格 |...| → add_table() · 标题 # → add_heading()
· LaTeX $...$ / $$...$$ 转 Consolas 字体 · add_bibl_field() 注入 Zotero 参考文献域
· python-docx 保存为 output_zotero_YYMMDD_HHMMSS.docx

5. 安装向导
· 9步逐步确认: 环境扫描→Miniconda→MinerU环境→PyTorch→MinerU包→模型→Zotero→BBT→GPU加速
· 每步调用对应的 conda/pip/mineru CLI 命令
· setup_runner.execute_step() → subprocess.Popen 实时输出到 WebSocket

6. 实时日志推送
· Python 后端 ThreadPoolExecutor → asyncio.run_coroutine_threadsafe(broadcast_log)
· 前端 WebSocket /ws/logs → addLog() → 同时写入 logPanelA/B/S

技术栈:
· 核心引擎: MinerU 3.1.x (OpenDataLab) — pipeline/hybrid/vlm 三大后端
· VLM 模型: Qwen2VL 1.2B (MinerU2.5-Pro-2604) — 视觉大模型布局分析
· Pipeline 模型: PDF-Extract-Kit-1.0 — 传统规则引擎 (Layout/PP-DocLayoutV2/MFR/Table)
· 深度学习: PyTorch + Transformers (HuggingFace) + CUDA 12.1 · hf_xet 加速下载
· 后端: FastAPI + Uvicorn (Python 3.10) → REST 14端点 + WebSocket
· 前端: Electron 33 + Chromium 渲染 · 原生 HTML/CSS/JS (单文件, 无框架)
· 文献: Zotero BetterBibTeX JSON → python-docx 生成 OOXML 域代码
· 打包: electron-builder portable · 单文件 .exe
